۸ روش اتصال قدرتمند

انتخاب با شماست؛ از پروتکل‌های مدرن تا روش‌های دور زدن فیلترینگ.

Xray

اتصال از طریق هسته Xray با پشتیبانی از VLESS, VMess, Trojan و Shadowsocks.

Psiphon

تونل زنی Psiphon با انتخاب خروجی خودکار و قابلیت Kill Switch.

Cloudflare WARP

اتصال به WARP با استفاده از داده‌های WireGuard اختصاصی اپ.

OpenVPN

اتصال با ایمپورت پروفایل‌های .ovpn و پشتیبانی از TCP/UDP.

SSTP

پروتکل امن Socket Tunneling با پشتیبانی از سرورهای سفارشی.

DNS Changer

تغییر خودکار DNS برای دسترسی به سایت‌های تحریم شده.

Proxy

اتصال از طریق پروکسی محلی روی 127.0.0.1:4444.

Slow DNS

دور زدن فیلترینگ با استفاده از تکنیک Slow DNS.

🚀 حالت بتا: Mix (چند مرحله‌ای)

ترکیب هوشمند پروتکل‌ها و DNS بلوک‌ها به ترتیب دلخواه برای دور زدن پیشرفته‌ترین فیلترینگ‌ها.
